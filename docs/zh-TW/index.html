YouTube Chat Dock

聊天室在影片旁邊，不是壓在上面。

一個免費、開放原始碼的 Chrome 擴充功能，把 YouTube 的直播聊天室與聊天重播變成可以調整寬度的側邊欄 —— 一般播放頁、劇院模式與真正的全螢幕都同樣有效。播放器本身會縮小以容納聊天室，所以聊天室不會遮住影片，影片也不會被裁切。

怎樣讓 YouTube 直播聊天室排在影片旁邊？

裝一個能把它停靠住的擴充功能。YouTube 本身完全沒有給你控制權：三種顯示模式裡，都找不到任何可以調整聊天室寬度或移動位置的設定。

YouTube Chat Dock 只是把頁面上原本就有的聊天室重新排版，所以它仍然是 YouTube 自己的聊天室，Super Chat、表情符號、管理工具、會員徽章全部照常運作。沒有任何東西被重寫，也沒有任何東西經過中轉。改變的只有聊天室放在哪裡、以及有多寬。

YouTube 的直播聊天室可以調整寬度嗎？

可以，拖曳影片與聊天室之間的分隔線就行。一般播放頁、劇院模式與全螢幕各自記住自己的寬度，所以切到全螢幕不會弄亂你的版面。

  • 拖曳分隔線，寬度最窄可到 120px。
  • 雙擊分隔線即可回復預設寬度。
  • 也可以聚焦分隔線後用方向鍵調整，Shift 是大幅度，Home 與 End 直接到最小與最大。
  • 把滑鼠移到分隔線上按 ⇆，聊天室會移到另一側，選擇會被記住。
  • 或者用工具列設定面板的滑桿，拖動時畫面會即時跟著變。

為什麼劇院模式下聊天室會跑到影片下面？

因為劇院模式下 YouTube 會把播放器收窄、在旁邊預留一格空位，然後把那格空位留空，改把聊天室排到影片下方。這是 YouTube 自己的行為，不是任何擴充功能的問題。

這件事在擴充功能開啟與完全關閉的狀態下都量過，版面一模一樣：播放器旁邊有一格大約 450px 的欄位被預留下來卻空著，而聊天室被丟到下面。YouTube Chat Dock 把那格預留的位置填上它本來就該放的聊天室，而且讓你連那格預留寬度本身都能調整 —— 所以播放器的寬度和聊天室的寬度永遠一致。

全螢幕的時候還能看聊天室嗎？

看得到，但不是照你的意思：寬度改不了，位置也選不了。裝了這個擴充功能之後，聊天室會用自己記住的寬度停靠在影片旁邊，不遮住任何東西，影片也不會被裁切。

舊直播的聊天重播也適用嗎？

適用。影片重溫的聊天重播，停靠與調整寬度的行為跟直播中的聊天室完全一樣，不需要另外設定。

可以把聊天室移到左邊嗎？

可以。把滑鼠移到分隔線上按 &#8646; 按鈕，或在工具列的設定面板切換。這個選擇會一直記住，換影片也不會變。

在阿拉伯文這類由右至左的介面語言下，這個切換會跟著整個版面一起鏡像，而不是反過來，所以「另一側」永遠就是你看到的那一側。

有哪些設定？

啟用開關、語言選擇、左右切換、三個寬度滑桿，還有一鍵回復預設值，全部在工具列的設定面板裡。不過你其實不必打開它：分隔線就能做到滑桿能做的事，也可以用方向鍵調整。

YouTube Chat Dock 會收集資料嗎？

不會。不收集、不傳送，而且根本不發出任何網路連線 —— 沒有分析、沒有追蹤、沒有遠端設定。你的設定只存在自己的瀏覽器裡，永遠不會離開這台裝置。

  • 不收集、不傳送、不販售任何資料 —— 不做匿名化，也不做彙整
  • 沒有任何網路連線，沒有分析，沒有追蹤
  • 沒有背景執行的 service worker；不在 YouTube 時完全不會執行
  • 不需要帳號、不需要登入、沒有雲端同步
  • 沒有 host 權限 —— 只能在 youtube.com 上運作，其他地方一概不行
  • 只有一個 storage 權限，而 Chrome 安裝時不會為它跳出任何提示

那唯一的 storage 權限存在的理由只有一個：設定面板是獨立的擴充功能頁面，否則沒有辦法把你的選擇傳到它正在設定的那個分頁。完整政策：store/PRIVACY.md。整個擴充功能就是一份樣式表加一支小腳本，MIT 授權，大約十分鐘可以從頭讀到尾。

Edge、Brave、Opera、Arc 可以用嗎？

可以。這是一個沒有任何依賴的 Manifest V3 擴充功能，支援 Chrome 88 以上，以及任何以 Chromium 為基礎的瀏覽器 —— Edge、Brave、Opera、Vivaldi、Arc。

它發布在 Chrome 線上應用程式商店，Edge 與其他 Chromium 瀏覽器都可以直接從那裡安裝。它不是 Firefox 附加元件。

支援哪些語言？

12 種：English、繁體中文、简体中文、日本語、한국어、Español、Português、Français、Deutsch、Русский、العربية、हिन्दी。

語言選擇與瀏覽器的語言互不相干，所以 Chrome 可以是一種語言，這個擴充功能是另一種。由右至左的版面是正確處理的，不是碰巧鏡像。

有什麼限制？

有兩點值得知道。瀏覽器視窗寬度低於 1000px 時它會刻意不生效；另外，清除 youtube.com 的網站資料會讓你存的寬度回復預設。

  • 視窗寬度低於 1000px 時。YouTube 在那裡會切換成單欄版面，把聊天室排到影片下方。這個擴充功能選擇不介入，而不是去跟 YouTube 自己的響應式版面對抗。
  • 清除網站資料會重設寬度。寬度存在 localStorage，這樣才能在頁面繪製之前就套用，也正是這一點讓版面不會每次載入都閃一下。

怎樣安裝？

在 Chrome 線上應用程式商店按一下安裝，然後重新載入已經開著的 YouTube 分頁就好。不需要任何設定就會變成側邊欄。

從商店安裝

加到 Chrome，然後重新載入 YouTube 分頁。Chrome 不會要你同意任何東西。

從原始碼安裝

複製這個 repo，開啟 chrome://extensions/，打開開發人員模式，按「載入未封裝項目」並選擇該資料夾。不需要建置，也沒有任何依賴。
